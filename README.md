# Invasión Espacial 🚀👾

**Invasión Espacial** es un juego arcade desarrollado con Python y Pygame. Controlas una nave espacial que debe destruir a los alienígenas invasores antes de que lleguen a la Tierra. ¡Disfruta del clásico estilo retro con sonido, gráficos y mucha acción!

## 🎮 Características

- Jugabilidad simple y divertida
- Enemigos múltiples con movimiento aleatorio
- Sistema de puntuación
- Sonido de fondo envolvente
- Gráficos coloridos tipo arcade

## 🛠 Requisitos

- Python 3.8 o superior
- Pygame (`pip install pygame`)

## ▶️ Cómo jugar

1. Ejecuta el archivo `main.py` o `invasion_espacial.py`.
2. Usa las flechas izquierda y derecha para mover tu nave.
3. Presiona `ESPACIO` para disparar balas.
4. ¡Evita que los enemigos lleguen al fondo de la pantalla!
